                                                                                4.1.2. Data annotation
                                                                                    Data annotation is the process of adding labels to the objects in the
                                                                                collected images, following a labeling scheme. For few-shot detection,
                                                                                the labeling scheme of the PASCAL VOC dataset [47] was followed in
                                                                                this study using an annotation tool named LabelImg. Labels for each
                                                                                object instance contain two kinds of information: object class name and
                                                                                object coordinates. Labels for each image containing multiple objects
                                                                                were stored in an (Extensible Markup Language) XML file, which is a
                                                                                common markup language format for storing structured data. For
                                                                                attribute recognition, the labeling scheme of the PEdesTrian Attribute
                                                                                (PETA) dataset [48] was followed, which requires adding multiple
                                                                                attribute tags to an object in its existing XML file. Those multi-label
                                                                                attributes were then converted into one-hot encoding as the input for
                                                                                attribute recognition.
