                                                                                         We selected 3D LiDAR SLAM for BIM-integrated localization based
                                                                                     on compatibility with processed BIM geometry, robustness to con-
                                                                                     struction challenges, and sensor compatibility. We evaluated multiple
                                                                                     paradigms: Visual SLAM struggles with challenging lighting and poor
                                                                                     visual features common on construction sites, and visual features are
                                                                                     not directly compatible with BIM geometry. While 2D LiDAR SLAM
                                                                                     is common in mobile robotics, its single scanning plane struggles to
Fig. 4. BIM model, processed using IfcOpenShell to selectively extract its           detect building structures like walls when floor-level obstacles cause
structural geometry to a point cloud using Open3D, which serves as initial           occlusion, preventing accurate BIM-referencing.
data for navigation and SLAM.                                                            Consequently, we selected 3D LiDAR SLAM as our localization ap-
                                                                                     proach. This choice offers several advantages in our context: (1) it cap-
                                                                                     tures detailed 3D point clouds that enable direct geometric comparison
                                                                                     with structural BIM components; (2) it remains relatively unaffected
                                                                                     by obstacles occluding walls by sensing above floor-level clutter; (3)
                                                                                     it provides reliable performance even in visually challenging environ-
                                                                                     ments with poor lighting or poor features; and (4) it aligns well with the
                                                                                     available sensors installed on our robot. Crucially, the geometric cor-
                                                                                     respondence between 3D LiDAR data and 3D BIM elements facilitates
                                                                                     consistent localization relative to the as-planned model.
                                                                                         After evaluating Cartographer, hdl_graph_slam, and lidarslam_ros2, we
                                                                                     selected LiDAR SLAM by Kitware for its ability to initialize directly with
                                                                                     point cloud data from BIM-derived reference geometry. This implemen-
                                                                                     tation uses Iterative Closest Point (ICP) to compare captured LiDAR
                                                                                     point clouds against its internal map representation supporting multiple
                                                                                     feature types.
                                                                                         From the available feature types, we utilize edges and planes fea-
                                                                                     tures, well-suited to both environment and BIM reference. Since BIM
                                                                                     models consist primarily of planar surfaces (walls, floors, ceilings), we
                                                                                     initialize the SLAM’s plane map with a BIM-derived point cloud while
                                                                                     leaving the edge map empty. BIM data acts as a prior soft constraint,
                                                                                     guiding but not forcing building structure alignment. The system dy-
                                                                                     namically adds new features based on sensor observations, adapting to
                                                                                     differences between as-designed BIM and actual site conditions.
                                                                                         This approach requires approximate initial robot location, a com-
                                                                                     mon limitation of LiDAR-based localization affecting deployment con-
                                                                                     venience. While global localization would eliminate manual setup,
                                                                                     structural symmetry in indoor environments makes this challenging
                                                                                     with LiDAR alone. Once initialized, our system performed robustly and
                                                                                     achieved precise positioning despite significant BIM-reality differences.
